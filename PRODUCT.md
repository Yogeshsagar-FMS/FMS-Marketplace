# FMS Circle

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Confirmed by the user: FMS Delhi students buying and passing on books, room essentials, gadgets, fashion, and bicycles. Keep the FMS Circle name.

## Product Purpose

Help students find useful secondhand items within their campus community and list things they no longer need. Prioritize price, condition, pickup, and direct seller information.

## Operating Context

Student budgets, reading lists, room setup, and batch handovers. Mobile browsing is a primary use case (design inference).

## Capabilities and Constraints

Existing stack is JavaScript, CSS, Vite. Preserve search, categories, sorting, favourites, item details, photo upload, contact details, and locally persisted listings. Current build is a frontend prototype: sample listings are demonstrations; browser-local data is not shared. No verification, payments, authentication, or private messaging is available. User confirmed browser-local functionality for now, with login and a shared backend to be added later. Keep storage behind a repository boundary to support that migration. Never claim students are verified or fabricate marketplace activity.

## Brand Commitments

User requests a complete redesign from scratch with a distinctive, non-generic design grounded in purpose and audience. Existing name: FMS Circle; no requirement to retain the old visual language. In the latest feedback, the user rejected the restrained catalogue and asked for unmistakable FMS identity, a fun landing page, and visible animation. Confirmed creative freedom for maroon/eagle identity, oversized type, and an animated campus handover collage.

## Evidence on Hand

README.md describes prototype scope. Existing src/main.js contains demonstration inventory. No genuine customer testimonials or activity metrics are supplied.

## Product Principles

Make finding and comparing an item quick. Keep condition and pickup visible. Let students save and publish with little friction. Be clear about sample data and browser-only persistence.
